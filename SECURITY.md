# Security

Report vulnerabilities to **we@saerbridge.com**.

Please:

- Describe the issue, affected endpoint or page, and steps to reproduce.
- Include request IDs from `X-Request-Id` if you have them.
- Do not include other people’s personal information in the report.
- Do not disclose the issue publicly until we have had a reasonable chance to fix it.

This is a privately run public-interest service. We will acknowledge reports and tell you when a fix is available.

Do not test against production with destructive payloads. If you need a lab, say so.
